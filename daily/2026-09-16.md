## 一、SQL 的设计哲学

### 1.1 SQL 是什么？

SQL（Structured Query Language）是与数据库沟通的**唯一语言**。

> [!quote] 核心思想
> SQL 是**声明式**语言：你告诉数据库**要什么**，而不是**怎么做**。

```python
# 命令式（Python）：告诉计算机怎么做
results = []
for row in table:
    if row['status'] == 'completed':
        results.append(row['id'])
```

```sql
-- 声明式（SQL）：告诉数据库要什么
SELECT id FROM experiments WHERE status = 'completed';
```

> [!tip] 设计哲学
> 你不需要知道数据存在哪个文件、用什么索引、怎么遍历。只描述需求，数据库引擎自己决定执行策略。

### 1.2 关系模型基础

数据存储在**表（Table）**中，表由**行（Row）**和**列（Column）**组成。

```
experiments 表
┌────┬─────────────┬───────────┬──────────┐
│ id │ model       │ dataset   │ accuracy │
├────┼─────────────┼───────────┼──────────┤
│  1 │ CNN         │ DemoRF    │ 0.71     │  ← 一行
│  2 │ ResNet      │ DemoRF    │ 0.78     │
│  3 │ Transformer │ DemoRF    │ 0.86     │
└────┴─────────────┴───────────┴──────────┘
  ↑                                      ↑
 列名                                  数据
```

| 术语 | 说明 | 本例 |
|------|------|------|
| **表 (Table)** | 数据的结构化集合 | experiments |
| **列 (Column)** | 数据的属性/字段 | id, model, accuracy |
| **行 (Row)** | 一条具体记录 | id=1 的那条 CNN 记录 |
| **主键 (Primary Key)** | 唯一标识每行的列 | id |
| **NULL** | 未知或缺失的值 | accuracy 为 NULL |

## 二、SQL 基础语法

### 2.1 查询：SELECT

SELECT 是 SQL 中最常用的操作，用于**读取数据**。

```sql
SELECT 列名 FROM 表名 WHERE 条件 ORDER BY 列名 LIMIT 数量;
```

#### 基础查询

```sql
-- 查询所有列
SELECT * FROM experiments;

-- 查询指定列
SELECT id, model, accuracy FROM experiments;

-- 去重查询
SELECT DISTINCT dataset FROM experiments;
```

#### 条件筛选：WHERE

```sql
-- 等于
SELECT * FROM experiments WHERE model = 'CNN';

-- 不等于
SELECT * FROM experiments WHERE model != 'ResNet';

-- 大小比较
SELECT * FROM experiments WHERE accuracy >= 0.85;

-- 范围查询（含两端）
SELECT * FROM experiments WHERE snr_db BETWEEN -6 AND 0;

-- 多条件组合
SELECT * FROM experiments 
WHERE status = 'completed' AND accuracy >= 0.8;

-- 或条件
SELECT * FROM experiments 
WHERE model = 'CNN' OR model = 'ResNet';
```

#### 排序：ORDER BY

```sql
-- 升序（默认）
SELECT * FROM experiments ORDER BY accuracy ASC;

-- 降序
SELECT * FROM experiments ORDER BY accuracy DESC;

-- 多列排序：先按 accuracy 降序，同分按 id 升序
SELECT * FROM experiments 
ORDER BY accuracy DESC, id ASC;
```

#### 限制数量：LIMIT

```sql
-- 只返回前 3 条
SELECT * FROM experiments LIMIT 3;

-- 分页：跳过前 10 条，取 5 条
SELECT * FROM experiments LIMIT 5 OFFSET 10;
```

### 2.2 NULL 的特殊性

> [!warning] NULL 不是值
> NULL 表示"未知"，不是 0、空字符串或 'NULL' 字符串。

```sql
-- ❌ 错误：NULL 不能用 = 比较
SELECT * FROM experiments WHERE accuracy = NULL;

-- ✅ 正确：用 IS NULL
SELECT * FROM experiments WHERE accuracy IS NULL;

-- ✅ 正确：用 IS NOT NULL
SELECT * FROM experiments WHERE accuracy IS NOT NULL;
```

> [!note] NULL 的运算规则
> 任何值与 NULL 运算结果仍是 NULL：
> - `NULL + 1 = NULL`
> - `NULL = NULL` 结果是 NULL（不是 TRUE）
> - `NULL != NULL` 结果是 NULL（不是 TRUE）

### 2.3 模式匹配：LIKE

```sql
-- % 匹配任意多个字符
SELECT * FROM experiments WHERE model LIKE 'Trans%';
-- 匹配: Transformer

-- _ 匹配单个字符
SELECT * FROM experiments WHERE model LIKE 'C_N';
-- 匹配: CNN

-- 包含 'Demo'
SELECT * FROM experiments WHERE dataset LIKE '%Demo%';
```

### 2.4 插入数据：INSERT

```sql
-- 插入一行
INSERT INTO experiments (id, model, dataset, seed, snr_db, accuracy, status, created_at)
VALUES (13, 'BERT', 'DemoRF', 6, -6, 0.92, 'completed', '2026-09-16');

-- 插入多行
INSERT INTO experiments (id, model, dataset, seed, snr_db, accuracy, status, created_at)
VALUES 
(14, 'BERT', 'DemoRadar', 7, 0, NULL, 'running', '2026-09-16'),
(15, 'GPT', 'DemoRadar', 8, -12, NULL, 'failed', '2026-09-16');
```

### 2.5 更新数据：UPDATE

```sql
-- 更新单个字段
UPDATE experiments 
SET accuracy = 0.95, status = 'completed' 
WHERE id = 6;

-- 更新多行（谨慎！）
UPDATE experiments 
SET status = 'failed' 
WHERE accuracy IS NULL;
```

> [!danger] 没有 WHERE 会更新所有行！
> `UPDATE experiments SET status = 'completed';` 会让所有记录都变成 completed。

### 2.6 删除数据：DELETE

```sql
-- 删除单行
DELETE FROM experiments WHERE id = 100;

-- 删除多行
DELETE FROM experiments WHERE status = 'failed';

-- 删除所有行（表结构保留）
DELETE FROM experiments;
```

> [!danger] 没有 WHERE 会删除所有行！
> 这和 `DROP TABLE` 不同：DELETE 保留表结构，DROP 连表都删掉。

## 三、SQL 执行顺序

SQL 的**书写顺序**和**执行顺序**不同：

```sql
-- 书写顺序
SELECT 列名        -- ④
FROM 表名          -- ①
WHERE 条件         -- ②
ORDER BY 列名      -- ③
LIMIT 数量;        -- ⑤
```

```
执行顺序：
① FROM     → 找到表
② WHERE    → 筛选行
③ ORDER BY → 排序
④ SELECT   → 选列
⑤ LIMIT    → 截断
```

> [!note] 为什么这很重要？
> 你不能在 WHERE 中使用 SELECT 定义的别名，因为 WHERE 先执行。
> 但可以在 ORDER BY 中使用别名。

## 四、数据类型

SQLite 是**动态类型**数据库，但良好实践应指定类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| `INTEGER` | 整数 | `id INTEGER PRIMARY KEY` |
| `REAL` | 浮点数 | `accuracy REAL` |
| `TEXT` | 文本 | `model TEXT NOT NULL` |
| `BLOB` | 二进制数据 | 图片、文件 |
| `NULL` | 空值 | 无类型 |

### 约束

```sql
CREATE TABLE experiments (
    id INTEGER PRIMARY KEY,      -- 主键，唯一标识
    model TEXT NOT NULL,         -- 不能为空
    accuracy REAL CHECK (accuracy >= 0 AND accuracy <= 1),  -- 值域检查
    status TEXT CHECK (status IN ('completed', 'running', 'failed')),  -- 枚举检查
    seed INTEGER DEFAULT 0       -- 默认值
);
```

| 约束 | 说明 |
|------|------|
| `PRIMARY KEY` | 主键，唯一且不为空 |
| `NOT NULL` | 不能为空 |
| `UNIQUE` | 值不能重复 |
| `CHECK` | 自定义条件检查 |
| `DEFAULT` | 默认值 |
| `FOREIGN KEY` | 外键关联（D2 学习） |

## 五、小结：SQL 的本质

> [!summary] SQL 设计哲学
> 1. **声明式**：描述你要什么，不描述怎么做
> 2. **集合思维**：操作的是行的集合，不是单行
> 3. **基于表**：所有数据都存在于表中
> 4. **NULL 特殊**：三值逻辑（TRUE/FALSE/UNKNOWN）
> 5. **大小写不敏感**：关键字和函数名不区分大小写

## Python CRUD 示例

```python
import sqlite3
from contextlib import closing

with closing(sqlite3.connect('data/day01.sqlite')) as conn:
    # INSERT - 插入
    conn.execute(
        '''INSERT INTO experiments 
           (id, model, dataset, seed, snr_db, accuracy, status, created_at) 
           VALUES (?, ?, ?, ?, ?, ?, ?, ?)''',
        (100, 'TestModel', 'TestData', 0, 0, 0.5, 'completed', '2026-09-16')
    )
    conn.commit()
    
    # SELECT - 查询
    row = conn.execute(
        'SELECT * FROM experiments WHERE id = ?', (100,)
    ).fetchone()
    print(row)
    
    # UPDATE - 更新
    conn.execute(
        'UPDATE experiments SET accuracy = ? WHERE id = ?', 
        (0.75, 100)
    )
    conn.commit()
    
    # DELETE - 删除
    conn.execute('DELETE FROM experiments WHERE id = ?', (100,))
    conn.commit()
```

> [!tip] 参数绑定
> 始终使用 `?` 占位符，不要用 f-string 拼接，防止 SQL 注入。
