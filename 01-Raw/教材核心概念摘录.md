# 教材核心概念摘录（只增不改，用自己的话重写进 02-Wiki）

> 来源：Alex Petrov《Database Internals》，本地 PDF（书页 + 20 = PDF 页）。

## 前言（PDF 14–16）

- Audience：给用数据库的软件开发者、架构师；假设有后端和数据库使用经验。
- Scope：只讲存储引擎与分布式内部机制，不讲查询语言。
- 学基础概念的意义：新算法多是对经典算法的修补，懂历史才懂动机。

## 第 1 章 8–10 页（PDF 28–30）：DBMS 架构

- 请求路径：transport → query processor（解析/校验/权限）→ optimizer（执行计划）
  → execution engine（本地+远程）→ storage engine。
- 存储引擎五件套：transaction manager、lock manager、access methods、
  buffer manager、recovery manager。

## 第 1 章 17–22 页（PDF 37–42）：数据文件与索引文件

- 索引用来不每次都全表扫描（auxiliary data structures）。
- 堆文件无序、靠索引找；哈希文件按桶；索引组织表（IOT）数据存索引里。
- 主索引 vs 辅索引；clustered（数据顺序跟键走）vs nonclustered。
- 三旋钮：Buffering、Mutability、Ordering。

## 第 2 章 25–42 页（PDF 45–62）：B 树基础

- BST 上磁盘烂在：高度 = 寻道次数；局部性差。
- B 树要求：高 fanout、低 height；节点即页。
- N 键 + N+1 指针；根/中间/叶；occupancy；B+ 值只放叶。
- 查找：根走到叶，读盘次数 = 层数；节点内二分。
- 分裂四步：申请新节点 → 搬一半 → 放新元素 → 父记路牌；只根分裂时长高。
- 合并三步：右搬左 → 删父指针 → 删右节点。

## 第 5 章 79–80 页（PDF 99–100）：ACID

- Transaction = indivisible logical unit of work，多步作一步。
- A：全做或全不做，commit 可见、abort 回滚、可重试。
- C：合法到合法，用户也要负责的属性。
- I：并发互不干扰，何时可见由隔离级别定。
- D：commit 落盘，断电不丢。
- 本地三件套：transaction manager、lock manager、page cache。
