# 聚合统计

## 一句话定义

先分组再对每组算一个数：行数变少，信息变浓。

## 核心机制

```
FROM → JOIN → WHERE（筛行）→ GROUP BY（分组）→ HAVING（筛组）→ SELECT → ORDER BY
```

- `COUNT(*)` 数行（含 NULL）；`COUNT(列)`/`AVG`/`MAX`/`MIN`/`SUM` 跳过 NULL。
- `WHERE COUNT` 报错（`misuse of aggregate`）：WHERE 时还没分组。
- 浮点 AVG 有灰尘（实测 0.7999…）：展示比较前包 `ROUND(x, 2)`。
- 子查询先算内层；`WITH` 是起了名字的子查询。
- 参数绑定：`?` 占位符，不用 f-string。
- **套路**：`LEFT JOIN + GROUP BY` 做含 0 统计。

## 代码模板

```sql
SELECT datasets.name, COUNT(runs.id) FROM datasets
JOIN runs ON runs.dataset_id = datasets.id
GROUP BY datasets.name HAVING COUNT(runs.id) > 2;
```
